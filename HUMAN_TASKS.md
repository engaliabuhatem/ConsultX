# HUMAN_TASKS.md

Everything below requires a real account, real payment, or legal authority — none of it
can be done by writing more code. Two items (marked ★) come from what's actually missing
in the source files, on top of the standard list the build prompt asked for.

| Task | Why it's a human task |
|---|---|
| ★ Supply real contact details (phone, email, address, social links) | The only values in the source files are placeholders (`+123-456-7890`, `info@consultx.com`) |
| ★ Supply a real project list for the Projects/Case Studies section | Onboarding materials ask founders for 15 prior projects; none were provided — see `PROJECT_BRIEF.md` |
| Purchase the domain name | Requires payment and an account with a registrar |
| Purchase hosting/a VPS and get SSH access | Requires payment and a real account |
| Point the domain to the server (DNS) | Done from the registrar's control panel, owner access only |
| Activate the SSL certificate on the live server | Requires the domain already pointed at a live server |
| Google accounts (Analytics, Search Console, Maps API) | Require the company's own Google account |
| reCAPTCHA keys | Issued from the company's own Google account |
| Transactional email provider (SendGrid/Mailgun/SMTP) | Requires a real account and credentials |
| High-resolution logo, real project photos, final approved copy | IP and brand decisions belong to the company |
| Legal review of privacy policy and terms | Requires a lawyer qualified for the operating jurisdiction |
| Confirm the color palette conflict (see `PROJECT_BRIEF.md` item 4) | Brand decision, not an engineering one |
| Confirm official name spelling/casing (`PROJECT_BRIEF.md` item 5) | Legal/trademark decision |
| Final design sign-off before launch | Business decision belonging to the company |
| Backup/uptime monitoring subscription | Requires payment and choosing a provider |
